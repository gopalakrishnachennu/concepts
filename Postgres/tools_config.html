3. pgBench - Performance Benchmarking

pgBench runs benchmark tests to measure database performance under various loads.

-- Initialize benchmark database pgbench -i -s 50 database_name -- -i: initialize, -s 50: scaling factor (50x default size) -- Run simple benchmark (read-write) pgbench -c 10 -j 2 -t 1000 database_name -- -c 10: 10 concurrent clients -- -j 2: 2 worker threads -- -t 1000: 1000 transactions per client -- Run for specific duration pgbench -c 20 -j 4 -T 60 database_name -- -T 60: run for 60 seconds -- Read-only benchmark pgbench -c 10 -j 2 -t 1000 -S database_name -- -S: select-only (read-only) -- Custom benchmark script pgbench -c 10 -j 2 -t 1000 -f custom_script.sql database_name -- View detailed progress pgbench -c 10 -j 2 -T 60 -P 5 database_name -- -P 5: show progress every 5 seconds

postgresql.conf Configuration

The postgresql.conf file controls all PostgreSQL server behavior. Changes require reload or restart depending on the parameter.

Configuration Hierarchy

Critical Configuration Categories

1. Memory Settings
-- Shared buffer pool (25% of RAM recommended) shared_buffers = 4GB -- Working memory per operation work_mem = 64MB -- Maintenance operations memory maintenance_work_mem = 512MB -- Effective cache size (hint for query planner) effective_cache_size = 12GB -- Maximum prepared transactions max_prepared_transactions = 0
2. Connection Settings
-- Maximum concurrent connections max_connections = 100 -- Superuser reserved connections superuser_reserved_connections = 3 -- Connection timeout tcp_keepalives_idle = 60 tcp_keepalives_interval = 10 tcp_keepalives_count = 5
3. WAL (Write-Ahead Log) Settings
-- WAL level: minimal, replica, logical wal_level = replica -- WAL buffer size wal_buffers = 16MB -- Minimum WAL size to keep min_wal_size = 1GB max_wal_size = 4GB -- WAL writer delay wal_writer_delay = 200ms -- Synchronous commit mode synchronous_commit = on -- on, off, remote_write, local, remote_apply
4. Query Planner Settings
-- Enable/disable specific scan types enable_seqscan = on enable_indexscan = on enable_bitmapscan = on -- Cost parameters random_page_cost = 4.0 seq_page_cost = 1.0 cpu_tuple_cost = 0.01 cpu_index_tuple_cost = 0.005 -- Parallelism max_parallel_workers_per_gather = 4 max_parallel_workers = 8
5. Checkpoint Settings
-- Maximum time between automatic checkpoints checkpoint_timeout = 5min -- Checkpoint completion target checkpoint_completion_target = 0.9 -- Warning threshold for checkpoint duration checkpoint_warning = 30s
6. Autovacuum Settings
-- Enable autovacuum autovacuum = on -- Max autovacuum workers autovacuum_max_workers = 3 -- Vacuum delay to avoid overwhelming system autovacuum_naptime = 1min autovacuum_vacuum_threshold = 50 autovacuum_analyze_threshold = 50 autovacuum_vacuum_scale_factor = 0.2 autovacuum_analyze_scale_factor = 0.1

Managing Configuration

-- View current configuration SELECT name, setting, unit, context FROM pg_settings WHERE name LIKE '%work_mem%'; -- Change setting for current session SET work_mem = '128MB'; -- Change setting permanently (requires reload) ALTER SYSTEM SET shared_buffers = '8GB'; -- Reload configuration without restart SELECT pg_reload_conf(); -- Check if restart is required for a setting SELECT name, setting, context FROM pg_settings WHERE context = 'postmaster'; -- View pending restart settings SELECT name, setting, pending_restart FROM pg_settings WHERE pending_restart = true;

PostgreSQL Logging & Monitoring

Log Configuration Parameters

1. Basic Logging Setup
-- Where to log log_destination = 'stderr' -- stderr, csvlog, syslog, eventlog -- Logging collector process logging_collector = on -- Log directory and filenames log_directory = 'log' log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log' -- Log rotation log_rotation_age = 1d -- Rotate after 1 day log_rotation_size = 100MB -- Rotate after 100MB log_truncate_on_rotation = off
2. What to Log
-- Log level: DEBUG5, DEBUG1, INFO, NOTICE, WARNING, ERROR, LOG, FATAL, PANIC log_min_messages = warning log_min_error_statement = error -- Log specific events log_connections = on log_disconnections = on log_duration = off log_statement = 'none' -- none, ddl, mod, all -- Log slow queries log_min_duration_statement = 1000 -- Log queries over 1 second -- Log checkpoints log_checkpoints = on -- Log lock waits log_lock_waits = on deadlock_timeout = 1s -- Log autovacuum activity log_autovacuum_min_duration = 0 -- Log all autovacuum runs -- Log temporary files log_temp_files = 0 -- Log all temp file usage
3. Log Line Format
-- Log line prefix (timestamp, user, database, etc.) log_line_prefix = '%t [%p]: [%l-1] user=%u,db=%d,app=%a,client=%h ' -- Common prefix variables: -- %t = timestamp, %p = process ID, %u = user name -- %d = database, %h = host, %a = application name -- %l = log line number, %m = timestamp with milliseconds -- Include error context log_error_verbosity = default -- terse, default, verbose

PostgreSQL Catalog System (pg_catalog)

The pg_catalog schema stores all metadata about database objects, providing a complete view of the database structure.

Catalog Architecture

pg_database

Database info

pg_class

Tables, indexes

pg_attribute

Column info

pg_stat_*

Statistics

Essential Catalog Tables

1. pg_database - Database Information
-- List all databases with size SELECT datname AS database_name, pg_size_pretty(pg_database_size(datname)) AS size, datconnlimit AS connection_limit, datallowconn AS allow_connections FROM pg_database ORDER BY pg_database_size(datname) DESC; -- Database age (for vacuum monitoring) SELECT datname, age(datfrozenxid) AS transaction_age FROM pg_database ORDER BY age(datfrozenxid) DESC;
2. pg_class - Tables, Indexes, Sequences
-- List all tables with sizes SELECT schemaname, tablename, pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS total_size, pg_size_pretty(pg_relation_size(schemaname||'.'||tablename)) AS table_size, pg_size_pretty(pg_indexes_size(schemaname||'.'||tablename)) AS indexes_size FROM pg_tables WHERE schemaname = 'public' ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC; -- Find all indexes for a table SELECT indexname, indexdef FROM pg_indexes WHERE tablename = 'your_table_name';
3. pg_stat_activity - Current Activity
-- View all active connections and queries SELECT pid, usename, application_name, client_addr, state, query_start, state_change, LEFT(query, 100) AS query FROM pg_stat_activity WHERE state != 'idle' ORDER BY query_start; -- Find long-running queries SELECT pid, now() - query_start AS duration, usename, query FROM pg_stat_activity WHERE state = 'active' AND now() - query_start > interval '5 minutes' ORDER BY duration DESC; -- Kill a specific query SELECT pg_cancel_backend(pid); -- Graceful cancel SELECT pg_terminate_backend(pid); -- Force terminate
4. pg_stat_user_tables - Table Statistics
-- Comprehensive table statistics SELECT schemaname, relname AS table_name, seq_scan, seq_tup_read, idx_scan, idx_tup_fetch, n_tup_ins AS inserts, n_tup_upd AS updates, n_tup_del AS deletes, n_live_tup AS live_tuples, n_dead_tup AS dead_tuples, last_vacuum, last_autovacuum, last_analyze, last_autoanalyze FROM pg_stat_user_tables ORDER BY seq_scan + idx_scan DESC; -- Tables needing vacuum (high dead tuple ratio) SELECT schemaname, relname, n_dead_tup, n_live_tup, ROUND(n_dead_tup * 100.0 / NULLIF(n_live_tup, 0), 2) AS dead_ratio FROM pg_stat_user_tables WHERE n_dead_tup > 1000 ORDER BY dead_ratio DESC;
5. pg_stat_user_indexes - Index Usage
-- Find unused indexes SELECT schemaname, tablename, indexname, idx_scan AS index_scans, pg_size_pretty(pg_relation_size(indexrelid)) AS index_size FROM pg_stat_user_indexes WHERE idx_scan = 0 AND indexrelname NOT LIKE '%_pkey' ORDER BY pg_relation_size(indexrelid) DESC; -- Most used indexes SELECT schemaname, tablename, indexname, idx_scan, idx_tup_read, idx_tup_fetch FROM pg_stat_user_indexes ORDER BY idx_scan DESC LIMIT 20;
6. pg_locks - Lock Information
-- View current locks SELECT l.locktype, l.database, l.relation::regclass, l.page, l.tuple, l.transactionid, l.mode, l.granted, a.usename, a.query, a.query_start FROM pg_locks l LEFT JOIN pg_stat_activity a ON l.pid = a.pid WHERE NOT l.granted ORDER BY a.query_start; -- Find blocking queries SELECT blocked_locks.pid AS blocked_pid, blocked_activity.usename AS blocked_user, blocking_locks.pid AS blocking_pid, blocking_activity.usename AS blocking_user, blocked_activity.query AS blocked_statement, blocking_activity.query AS blocking_statement FROM pg_catalog.pg_locks blocked_locks JOIN pg_catalog.pg_stat_activity blocked_activity ON blocked_activity.pid = blocked_locks.pid JOIN pg_catalog.pg_locks blocking_locks ON blocking_locks.locktype = blocked_locks.locktype AND blocking_locks.database IS NOT DISTINCT FROM blocked_locks.database AND blocking_locks.relation IS NOT DISTINCT FROM blocked_locks.relation AND blocking_locks.pid != blocked_locks.pid JOIN pg_catalog.pg_stat_activity blocking_activity ON blocking_activity.pid = blocking_locks.pid WHERE NOT blocked_locks.granted;

1. Connection Metrics

-- Current connection count by state SELECT state, COUNT(*) AS count FROM pg_stat_activity GROUP BY state ORDER BY count DESC; -- Connection usage percentage SELECT COUNT(*) AS current_connections, setting::int AS max_connections, ROUND(COUNT(*) * 100.0 / setting::int, 2) AS usage_percent FROM pg_stat_activity, pg_settings WHERE name = 'max_connections'; -- Connections by database SELECT datname, COUNT(*) AS connections, COUNT(*) FILTER (WHERE state = 'active') AS active FROM pg_stat_activity WHERE datname IS NOT NULL GROUP BY datname ORDER BY connections DESC; -- Idle connections SELECT pid, usename, application_name, client_addr, now() - state_change AS idle_time FROM pg_stat_activity WHERE state = 'idle' ORDER BY idle_time DESC;

2. Transaction Metrics

-- Transaction rate per database SELECT datname, xact_commit AS commits, xact_rollback AS rollbacks, xact_commit + xact_rollback AS total_transactions, ROUND(xact_rollback * 100.0 / NULLIF(xact_commit + xact_rollback, 0), 2) AS rollback_ratio FROM pg_stat_database WHERE datname IS NOT NULL ORDER BY total_transactions DESC; -- Transactions per second (sample over 10 seconds) WITH t1 AS ( SELECT xact_commit + xact_rollback AS total FROM pg_stat_database WHERE datname = current_database() ), t2 AS ( SELECT pg_sleep(10), xact_commit + xact_rollback AS total FROM pg_stat_database WHERE datname = current_database() ) SELECT (t2.total - t1.total) / 10.0 AS tps FROM t1, t2; -- Long-running transactions SELECT pid, usename, now() - xact_start AS transaction_duration, state, query FROM pg_stat_activity WHERE xact_start IS NOT NULL AND now() - xact_start > interval '1 minute' ORDER BY transaction_duration DESC;

3. Cache Hit Ratio Metrics

-- Overall cache hit ratio (should be > 99%) SELECT SUM(heap_blks_read) AS heap_read, SUM(heap_blks_hit) AS heap_hit, SUM(heap_blks_hit) / (SUM(heap_blks_hit) + SUM(heap_blks_read)) AS ratio FROM pg_statio_user_tables; -- Cache hit ratio per table SELECT schemaname, relname, heap_blks_read, heap_blks_hit, ROUND(heap_blks_hit * 100.0 / NULLIF(heap_blks_hit + heap_blks_read, 0), 2) AS cache_hit_ratio FROM pg_statio_user_tables WHERE heap_blks_read + heap_blks_hit > 0 ORDER BY heap_blks_read DESC LIMIT 20; -- Index cache hit ratio SELECT schemaname, relname, indexrelname, idx_blks_read, idx_blks_hit, ROUND(idx_blks_hit * 100.0 / NULLIF(idx_blks_hit + idx_blks_read, 0), 2) AS cache_hit_ratio FROM pg_statio_user_indexes WHERE idx_blks_read + idx_blks_hit > 0 ORDER BY idx_blks_read DESC LIMIT 20; -- Shared buffer statistics SELECT name, setting, unit FROM pg_settings WHERE name IN ('shared_buffers', 'effective_cache_size');

4. I/O Performance Metrics

-- Disk I/O statistics per table SELECT schemaname, relname, heap_blks_read, heap_blks_hit, idx_blks_read, idx_blks_hit, toast_blks_read, toast_blks_hit, tidx_blks_read, tidx_blks_hit FROM pg_statio_user_tables ORDER BY heap_blks_read + idx_blks_read DESC LIMIT 20; -- WAL statistics SELECT pg_current_wal_lsn(), pg_walfile_name(pg_current_wal_lsn()); -- Database-wide I/O statistics SELECT datname, blks_read, blks_hit, tup_returned, tup_fetched, tup_inserted, tup_updated, tup_deleted FROM pg_stat_database WHERE datname IS NOT NULL ORDER BY blks_read DESC; -- Temporary file usage SELECT datname, temp_files, pg_size_pretty(temp_bytes) AS temp_size FROM pg_stat_database WHERE temp_files > 0 ORDER BY temp_bytes DESC;

5. Query Performance Metrics

-- Requires pg_stat_statements extension CREATE EXTENSION IF NOT EXISTS pg_stat_statements; -- Top 20 slowest queries by total time SELECT ROUND(total_exec_time::numeric, 2) AS total_time, calls, ROUND(mean_exec_time::numeric, 2) AS mean_time, ROUND(stddev_exec_time::numeric, 2) AS stddev_time, LEFT(query, 100) AS query FROM pg_stat_statements ORDER BY total_exec_time DESC LIMIT 20; -- Queries with highest average execution time SELECT ROUND(mean_exec_time::numeric, 2) AS avg_time, calls, LEFT(query, 100) AS query FROM pg_stat_statements WHERE calls > 10 ORDER BY mean_exec_time DESC LIMIT 20; -- Most frequently executed queries SELECT calls, ROUND(total_exec_time::numeric, 2) AS total_time, ROUND(mean_exec_time::numeric, 2) AS mean_time, LEFT(query, 100) AS query FROM pg_stat_statements ORDER BY calls DESC LIMIT 20; -- Queries with most rows returned SELECT calls, rows, ROUND(rows::numeric / calls, 2) AS rows_per_call, LEFT(query, 100) AS query FROM pg_stat_statements WHERE calls > 0 ORDER BY rows DESC LIMIT 20;

6. Lock and Blocking Metrics

-- Current lock count by type SELECT locktype, mode, COUNT(*) AS lock_count FROM pg_locks GROUP BY locktype, mode ORDER BY lock_count DESC; -- Locks waiting to be granted SELECT l.pid, l.locktype, l.relation::regclass, l.mode, l.granted, a.usename, a.query_start, now() - a.query_start AS wait_time FROM pg_locks l JOIN pg_stat_activity a ON l.pid = a.pid WHERE NOT l.granted ORDER BY wait_time DESC; -- Blocked and blocking query pairs SELECT blocked.pid AS blocked_pid, blocked.usename AS blocked_user, blocking.pid AS blocking_pid, blocking.usename AS blocking_user, now() - blocked.query_start AS blocked_duration, LEFT(blocked.query, 80) AS blocked_query, LEFT(blocking.query, 80) AS blocking_query FROM pg_stat_activity AS blocked JOIN pg_locks AS blocked_locks ON blocked.pid = blocked_locks.pid JOIN pg_locks AS blocking_locks ON blocking_locks.locktype = blocked_locks.locktype AND blocking_locks.database IS NOT DISTINCT FROM blocked_locks.database AND blocking_locks.relation IS NOT DISTINCT FROM blocked_locks.relation AND blocking_locks.pid != blocked_locks.pid JOIN pg_stat_activity AS blocking ON blocking.pid = blocking_locks.pid WHERE NOT blocked_locks.granted AND blocking_locks.granted;

pg_ctl - PostgreSQL Server Management

pg_ctl is the command-line utility for controlling PostgreSQL server instances including start, stop, restart, and status operations.

Server Lifecycle Animation

Server: STOPPED

Basic pg_ctl Commands

1. Starting the Server
-- Start PostgreSQL server pg_ctl start -D /path/to/data/directory -- Start with specific log file pg_ctl start -D /var/lib/postgresql/data -l /var/log/postgresql/server.log -- Start with options pg_ctl start -D /var/lib/postgresql/data -o "-c config_file=/etc/postgresql/postgresql.conf" -- Start and wait for completion pg_ctl start -D /var/lib/postgresql/data -w -t 60 -- Start in different modes pg_ctl start -D /var/lib/postgresql/data -m smart # Default pg_ctl start -D /var/lib/postgresql/data -m fast # Fast shutdown recovery pg_ctl start -D /var/lib/postgresql/data -m immediate # Immediate recovery
2. Stopping the Server
-- Smart shutdown (wait for clients to disconnect) pg_ctl stop -D /var/lib/postgresql/data -m smart -- Fast shutdown (disconnect clients, rollback transactions) pg_ctl stop -D /var/lib/postgresql/data -m fast -- Immediate shutdown (abort all processes, requires crash recovery) pg_ctl stop -D /var/lib/postgresql/data -m immediate -- Stop with timeout pg_ctl stop -D /var/lib/postgresql/data -t 30 -m fast -- Stop and wait for completion pg_ctl stop -D /var/lib/postgresql/data -w
3. Server Status and Information
-- Check server status pg_ctl status -D /var/lib/postgresql/data -- Output example: -- pg_ctl: server is running (PID: 12345) -- /usr/pgsql-14/bin/postgres "-D" "/var/lib/postgresql/data" -- Check if server is ready to accept connections pg_isready -h localhost -p 5432 -- Get detailed status with psql psql -U postgres -c "SELECT version();" psql -U postgres -c "SELECT pg_postmaster_start_time();"
4. Restart and Reload Operations
-- Restart server (stop + start) pg_ctl restart -D /var/lib/postgresql/data -m fast -- Restart with new options pg_ctl restart -D /var/lib/postgresql/data -o "-c shared_buffers=4GB" -- Reload configuration without restart pg_ctl reload -D /var/lib/postgresql/data -- Or from SQL SELECT pg_reload_conf(); -- Promote standby to primary (replication) pg_ctl promote -D /var/lib/postgresql/data
5. Advanced Operations
-- Initialize a new database cluster pg_ctl init -D /var/lib/postgresql/data -- Or use initdb directly initdb -D /var/lib/postgresql/data --encoding=UTF8 --locale=en_US.UTF-8 -- Register PostgreSQL as a service (Windows) pg_ctl register -N "PostgreSQL" -D "C:\PostgreSQL\data" -- Unregister service pg_ctl unregister -N "PostgreSQL" -- Kill specific backend process pg_ctl kill TERM 12345 # Graceful termination pg_ctl kill INT 12345 # Fast shutdown pg_ctl kill QUIT 12345 # Immediate shutdown

Shutdown Mode Comparison

Mode Behavior Wait for Clients Recovery Needed Use Case
smart Wait for all clients to disconnect Yes No Graceful maintenance, can take long
fast Disconnect clients, rollback transactions No No Standard shutdown (recommended)
immediate Abort all processes immediately No Yes Emergency only, requires crash recovery
