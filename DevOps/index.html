Advanced architecture plan

Target platform architecture

Identity: Entra ID, IAM Identity Center, SSO, MFA, RBAC, PIM
Source: GitHub Enterprise, Azure Repos, branch protection, CODEOWNERS
CI/CD: GitHub Actions, Azure DevOps, Jenkins, Argo CD
IaC: Terraform modules, remote state, policy checks, drift detection
Cloud: AWS landing zone and Azure landing zone with hub-spoke networking
Runtime: EKS, AKS, ECS, App Service, VM Scale Sets
Data: Aurora, RDS, DynamoDB, Azure SQL, Cosmos DB, Storage
Ops: Prometheus, Grafana, CloudWatch, Azure Monitor, SIEM

Production principles

  • Everything is versioned, reviewed, repeatable, observable, and recoverable.
  • Least privilege, encryption, audit logging, and policy checks are default.
  • Promote the same artifact across environments. Do not rebuild for production.
  • Use SLOs, incident reviews, DR drills, and backup restore tests to measure maturity.
  • Document tradeoffs: cost, reliability, security, complexity, and team ownership.
